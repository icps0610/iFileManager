# iFileManager

版本：0.9.0

Windows 雙窗格檔案管理工具，介面為繁體中文。

## 系統需求
- Windows 10 以上
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（Windows 11 已內建；若啟動時出現 WebView2 相關錯誤，請先安裝）

## 使用方式
不需安裝，直接執行 `iFileManager.exe` 即可。設定（分頁、排序、窗格大小、字級等）會自動保留到下次開啟。

## 注意事項
- 「刪除」會移到資源回收筒；「永久刪除」無法復原，請確認後再執行
- 網路磁碟或離線的路徑讀取可能較慢
- 執行檔若經過壓縮，少數防毒軟體可能誤判，可將其加入例外
- 遇到問題時，請附上記錄檔 `%LOCALAPPDATA%\iFileManager\fm.log`

## 功能

### 瀏覽
- 啟動時預設單窗格，按「＋ 第二窗格」開啟第二窗格，可切換左右或上下排列、互換位置，拖曳分隔線調整大小（雙擊分隔線平分）
- 每個窗格可開多個分頁，滑鼠中鍵點分頁即可關閉
- 每個窗格有上一頁、下一頁、上一層按鈕
- 麵包屑路徑列，點空白處可直接輸入路徑
- 依名稱篩選目前資料夾內容（篩選框預設收起，按按鈕或 Ctrl+F 開啟）
- 依名稱、修改時間、大小排序（再點一次反向）
- 修改時間、大小欄可個別顯示或隱藏，左右窗格各自設定
- 右側「位置」面板列出所有磁碟機與 Windows 快速存取；讀不到快速存取時改列常用資料夾
- 「磁碟」與「快速存取」可點標題各自收合，狀態會保留
- 可將目前資料夾釘選到 Windows 快速存取，或從面板上取消釘選
- 重新整理按鈕可一次更新磁碟、快速存取與檔案清單
- 插入或拔除 USB 等磁碟時自動更新磁碟清單

### 檔案操作
- 複製、剪下、貼上，支援拖放（拖放預設為移動，按住 Ctrl 為複製）
- 雙窗格時可直接複製或移動到對面窗格
- 目的地有同名項目時可選擇覆寫、略過或兩者都保留
- 複製、移動在背景執行，多個工作依序排隊，顯示進度、速率與剩餘時間，可隨時取消或移出佇列
- 新增資料夾、新增空白檔案、重新命名
- 刪除時移到資源回收筒；移到資源回收筒失敗時不會改為永久刪除
- 另有永久刪除（無法復原）
- 計算選取項目（含子資料夾）的總大小
- 複製路徑、在 Windows 檔案總管中顯示
- Windows 原生右鍵選單；無法顯示時改用內建的簡易選單

### 批次改名
可先預覽結果再執行，支援四種模式：

| 模式 | 說明 |
| --- | --- |
| 取代 | 尋找並取代文字，可選正規表示式、區分大小寫 |
| 前後綴 | 在檔名前後加上文字 |
| 範本 | 以 `{name}`（原檔名，不含副檔名）與 `{n}`（流水號，可設起始值、間隔、位數）組成新檔名 |
| 大小寫 | 全部大寫、全部小寫或字首大寫 |

可選擇是否連副檔名一起處理。

### 檢視
- 淺色模式（淺米黃色）與深色模式切換
- 介面字型使用 Fira Code（未安裝時改用微軟正黑體等系統字型）
- 顯示或隱藏隱藏檔
- 字級調整（14 到 30，右下角滑桿）
- 分頁、排序、窗格寬度與各項設定會在下次開啟時保留

## 快捷鍵

| 按鍵 | 功能 |
| --- | --- |
| Enter | 開啟 |
| Backspace／Alt+↑ | 上一層 |
| Alt+← ／ Alt+→ | 返回／前進 |
| Ctrl+R | 重新整理 |
| Ctrl+L | 輸入路徑 |
| Ctrl+F | 篩選名稱 |
| Ctrl+A | 全選 |
| Ctrl+C ／ Ctrl+X ／ Ctrl+V | 複製／剪下／貼上 |
| F2 | 重新命名 |
| F3 | 批次改名 |
| F5 ／ F6 | 複製到對面／移到對面 |
| F7 ／ Shift+F7 | 新增資料夾／新增檔案 |
| Del | 移到資源回收筒 |
| Shift+Del | 永久刪除 |
| Ctrl+T ／ Ctrl+W | 新分頁／關閉分頁 |
| Ctrl+U | 兩個窗格互換 |
| Tab | 切換作用窗格 |
| Esc | 取消選取；沒有選取時清除篩選 |
| ↑ ↓ PageUp PageDown Home End | 移動游標，搭配 Shift 可連續選取 |
| Ctrl+＋ ／ Ctrl+－ ／ Ctrl+0 | 放大／縮小／還原字級 |
