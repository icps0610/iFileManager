# iFileManager

版本：0.9.1

Windows 雙窗格檔案管理工具，介面為繁體中文。

<img width="1431" height="844" alt="iFileManager 截圖" src="https://github.com/user-attachments/assets/e90770fd-5db3-456c-91f8-d9e0e77ad6bc" />

## 系統需求
- Windows 10 以上
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（Windows 11 已內建；若啟動時出現 WebView2 相關錯誤，請先安裝）

## 使用方式
不需安裝，直接執行 `iFileManager.exe` 即可。設定（分頁、排序、窗格大小、字級等）會自動保留到下次開啟。

## 注意事項
- 「刪除」會移到資源回收筒；「永久刪除」無法復原，請確認後再執行
- 網路磁碟或離線的路徑讀取可能較慢
- 執行檔若經過壓縮，少數防毒軟體可能誤判，可將其加入例外

## 功能

### 瀏覽
- 啟動時預設單窗格，按「＋ 第二窗格」開啟第二窗格，可切換左右或上下排列、互換位置，拖曳分隔線調整大小（雙擊分隔線平分）
- 每個窗格可開多個分頁，滑鼠中鍵點分頁即可關閉
- 每個窗格有上一頁、下一頁、上一層按鈕
- 麵包屑路徑列，點空白處可直接輸入路徑
- 依名稱篩選目前資料夾內容（篩選框預設收起，按按鈕或 Ctrl+F 開啟）
- 依名稱、修改時間、大小排序（再點一次反向）
- 修改時間、大小欄可個別顯示或隱藏，左右窗格各自設定
- 右側「位置」面板列出所有磁碟機與 Windows 快速存取；讀不到快速存取時改列常用資料夾
- 「磁碟」與「快速存取」可點標題各自收合，狀態會保留
- 可將目前資料夾釘選到 Windows 快速存取，或從面板上取消釘選
- 重新整理按鈕可一次更新磁碟、快速存取與檔案清單
- 插入或拔除 USB 等磁碟時自動更新磁碟清單

### 檔案操作
- 複製、剪下、貼上，支援拖放（拖放預設為移動，按住 Ctrl 為複製）
- 拖放可直接拖到檔案總管、桌面或網頁上傳區
- 在空白處（或檔名右邊的空白）按住拖曳可拉框選取多個項目，按住 Ctrl 為加選
- 雙窗格時可直接複製或移動到對面窗格
- 目的地有同名項目時可選擇覆寫、略過或兩者都保留
- 複製、移動在背景執行，多個工作依序排隊，顯示進度、速率與剩餘時間，可隨時取消或移出佇列
- 新增資料夾、新增空白檔案、重新命名
- 刪除時移到資源回收筒；移到資源回收筒失敗時不會改為永久刪除
- 另有永久刪除（無法復原）
- 一次計算目前資料夾內所有子資料夾的大小，顯示在「大小」欄並可依大小排序
- 複製路徑、在 Windows 檔案總管中顯示
- Windows 原生右鍵選單；無法顯示時改用內建的簡易選單

### 批次改名
可先預覽結果再執行，支援四種模式：

| 模式 | 說明 |
| --- | --- |
| 取代 | 尋找並取代文字，可選正規表示式、區分大小寫 |
| 前後綴 | 在檔名前後加上文字 |
| 範本 | 以 `{name}`（原檔名，不含副檔名）與 `{n}`（流水號，可設起始值、間隔、位數）組成新檔名 |
| 大小寫 | 全部大寫、全部小寫或字首大寫 |

可選擇是否連副檔名一起處理。

### 檢視
- 淺色模式（淺米黃色）與深色模式切換
- 介面字型使用 Fira Code（未安裝時改用微軟正黑體等系統字型）
- 顯示或隱藏隱藏檔
- 字級調整（14 到 30，右下角滑桿）
- 分頁、排序、窗格寬度與各項設定會在下次開啟時保留

## 開發

以 Go 與 [Wails v2](https://wails.io/) 開發。

### 開發環境
- Windows 10 以上、WebView2 Runtime
- [Go](https://go.dev/dl/) 1.27 以上（目前以 Go 1.27.4 建置；go.mod 為 `go 1.27`，module 名稱 `ifilemanager`）
- Wails CLI v2（build.bat 會在找不到時自動安裝）
- 選用：[UPX](https://upx.github.io/)，加入 PATH 後 build.bat 會自動壓縮執行檔
- 首次建置需要網路（安裝 Wails CLI、下載相依套件）
- 版本號在 `wails.json` 的 `info.productVersion`

### 建置
在專案資料夾執行：

```bat
build.bat
```

腳本會依序：
1. 檢查 Go，未安裝 Wails CLI 時自動安裝
2. 執行 `go mod tidy`
3. 執行單元測試 `go test ./internal/...`，未通過即停止
4. 執行系統功能自我檢測（右鍵選單、快速存取、磁碟），未通過只顯示警告、仍繼續建置
5. 關閉執行中的 iFileManager（`taskkill /f /im iFileManager.exe`）
6. 執行 `wails build -clean -ldflags "-s -w"`
7. 若有安裝 UPX，執行 `upx --best --lzma` 壓縮執行檔（未安裝則略過；壓縮後可能被部分防毒誤判）

完成後輸出檔為 `build\bin\iFileManager.exe`。

### 記錄檔
執行記錄寫在 `%LOCALAPPDATA%\iFileManager\fm.log`，超過 1MB 時會清空重新記錄。

快速存取透過 PowerShell 讀取；程式啟動時會在背景預先讀取，記錄檔會寫入耗時，讀不到時前端會重試並沿用上次成功的清單。

### 專案結構

| 路徑 | 說明 |
| --- | --- |
| `main.go` | 程式進入點、視窗設定 |
| `app.go` | 提供給前端呼叫的後端 API、磁碟變更偵測、記錄檔 |
| `fatal_*.go` | 啟動失敗時顯示錯誤訊息 |
| `internal/fsops/` | 檔案操作核心：列目錄、複製／移動、批次改名、資源回收筒、右鍵選單、快速存取 |
| `frontend/dist/` | 前端介面（HTML、CSS、JavaScript，不需額外建置） |
| `frontend/wailsjs/` | Wails 自動產生的前端綁定 |
| `build/` | 圖示、Windows 資訊檔與建置輸出 |
| `build.bat` | 建置腳本 |
